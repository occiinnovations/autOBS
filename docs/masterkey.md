# Master Key

This document shows every single function in autOBS/Nodary. Use as reference.

## OBS (4-14)

4 - connect to OBS
5 - disconnect from OBS

6 - Start Recording
7 - Stop Recording

8 - Set Program Scene to Scene 1
9 - Set Program Scene to Scene 2

10 - Get Scene List

11 - Set Preview Scene to Scene 1
12 - Set Preview Scene to Scene 2

13 - Trigger Studio Mode Transition

14 - Toggle Virtual Camera
